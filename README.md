# Задание 1

## Задача 1

### Текст задачи

Разработать класс `QuadraticEquation`, представляющий квадратное уравнение $a \cdot x^2 + b \cdot x + c = 0$. 

Требования к классу:
1. Хранение коэффициентов $a$, $b$, $c$ в виде свойств (коэффициент $a \neq 0$).
2. Реализация конструкторов:
   - Конструктор по умолчанию (уравнение $1 \cdot x^2 + 0 \cdot x + 0 = 0$).
   - Параметризованный конструктор с проверкой $a \neq 0$ (при $a = 0$ выбрасывается `ArgumentException`).
   - Конструктор копирования.
3. Вычисляемое свойство для расчета дискриминанта $D = b^2 - 4ac$.
4. Метод `GetRoots()`, возвращающий массив действительных корней уравнения (2 корня, 1 корень или пустой массив, если дискриминант отрицателен).
5. Переопределение метода `ToString()` для текстового представления уравнения.
6. Перегрузка операторов:
   - Унарные операторы `++` и `--` (увеличение/уменьшение всех коэффициентов на 1).
   - Неявное приведение к типу `double` (возвращает дискриминант).
   - Явное приведение к типу `bool` (возвращает `true`, если корни существуют, т.е. $D \ge 0$).
   - Операторы сравнения `==` и `!=` для сравнения двух уравнений по коэффициентам, а также переопределение `Equals` и `GetHashCode`.

### Алгоритм решения

1. Создан класс `QuadraticEquation` с закрытыми свойствами коэффициентов и валидацией ненулевого значения $a$ в конструкторах.
2. Реализовано свойство `Discriminant`, вычисляющее $D = b^2 - 4ac$.
3. Метод `GetRoots()` проверяет знак дискриминанта и возвращает массив корней, рассчитанных по формулам $x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$.
4. Перегружены унарные операторы `++` и `--`, возвращающие новые экземпляры класса с измененными на 1 коэффициентами.
5. Реализованы операторы явного (`bool`) и неявного (`double`) приведения типов, а также логические операторы равенства `==` и `!=`.

# Задание 2

## Задача 1

### Текст задачи

Разработать графическое приложение на базе WPF (Windows Presentation Foundation) с использованием архитектурного паттерна MVVM (Model-View-ViewModel) для интерактивной работы с классом `QuadraticEquation`.

Графический интерфейс должен обеспечивать:
1. Ввод коэффициентов $a$, $b$, $c$ первого уравнения с мгновенным автоматическим пересчетом и отображением дискриминанта и корней.
2. Проверку и защиту от некорректного ввода (ввод буквенных символов, нулевой коэффициент $a$).
3. Вызов унарных операторов `++` и `--` по нажатию соответствующий кнопок с динамическим обновлением полей ввода и результатов.
4. Отображение результатов неявного приведения к `double` и явного приведения к `bool`.
5. Ввод коэффициентов второго уравнения и проверку эквивалентности двух уравнений с использованием перегруженных операторов `==` и `!=`.

### Алгоритм решения

1. **Model**: В качестве модели используется класс `QuadraticEquation`, созданный в Задании 1.
2. **ViewModel (`MainViewModel`)**:
   - Реализует интерфейс `INotifyPropertyChanged` для обеспечения двусторонней связки данных (Data Binding) с UI.
   - Содержит свойства ввода (`InputA`, `InputB`, `InputC`, `InputA2`, `InputB2`, `InputC2`) и свойства вывода результатов (`EquationText`, `DiscriminantText`, `RootsText`, `ImplicitDoubleText`, `ExplicitBoolText`, `ComparisonResult`).
   - Метод `Calculate()` вызывается автоматически при изменении любого коэффициента, производит валидацию и обновляет вычисляемые поля.
   - Команды `IncrementCommand`, `DecrementCommand` и `CompareCommand` (реализующие `ICommand` через `RelayCommand`) связывают кнопки UI с логикой работы операторов `++`, `--` и сравнения `==`/`!=`.
3. **View (`MainWindow.xaml`)**:
   - Разметка графического интерфейса с группировкой компонентов по карточкам (`GroupBox`).
   - Использованы элементы `TextBox` с подвязанными свойствами `UpdateSourceTrigger=PropertyChanged`, кнопки `Button`, привязанные к командам `ViewModel`, и текстовые блоки `TextBlock` для вывода результатов.
